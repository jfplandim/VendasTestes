# 🛒 VendasTestes

Sistema de vendas desenvolvido em Java como trabalho avaliativo da disciplina de Programação Orientada a Objetos.

## 📦 Sobre o Projeto

**VendasTestes** é uma aplicação Java que modela um domínio de vendas aplicando os princípios de POO — encapsulamento, herança, polimorfismo e abstração. O projeto foi desenvolvido como resposta a um quizz da disciplina e inclui testes de comportamento das entidades do sistema.

## 📁 Estrutura do Projeto

```
VendasTestes/
├── .idea/          # Configurações do IntelliJ IDEA
├── vendas/         # Módulo principal da aplicação
│   └── src/
│       ├── main/   # Código-fonte (entidades, serviços)
│       └── test/   # Testes unitários
└── .gitignore
```

## 🚀 Como Executar

### Pré-requisitos

- Java JDK 11 ou superior
- IntelliJ IDEA (recomendado) ou outra IDE Java

### Rodando pelo IntelliJ IDEA

1. Clone o repositório:
   ```bash
   git clone https://github.com/jfplandim/VendasTestes.git
   ```
2. Abra o IntelliJ IDEA e selecione **Open > pasta `vendas/`**
3. Aguarde a indexação do projeto
4. Execute a classe principal ou os testes pelo painel de testes da IDE

### Rodando os testes via terminal (Maven)

```bash
cd vendas
mvn test
```
